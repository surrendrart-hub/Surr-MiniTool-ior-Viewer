Dépose ton HDRI équirectangulaire ici sous le nom :

    hdri.jpg

Format attendu : JPEG équirectangulaire (ratio 2:1, ex. 2048x1024).
Le viewer chargera automatiquement ce fichier en premier.

S'il est absent ou inaccessible, le viewer tente une HDRI distante (jsdelivr),
puis se rabat sur un environnement procédural (généré en canvas) qui marche
toujours, même offline.
